# Clypsera 26

作者：**eddielee7318 BJC**

用于收集、整理和阅读个人资料的桌面工具。推荐运行 `Clypsera-v26-Setup.exe` 完成当前用户安装。安装包内置《Clypsera v26 零基础使用手册》，安装后可从开始菜单直接打开。

## 功能

- 自动记录文本剪贴板、复制时间、来源程序和来源窗口标题
- 设置可启用程序白名单，并可维护始终优先的黑名单；名单按进程名匹配，支持填写 `chrome` 或 `chrome.exe`
- 置顶悬浮窗显示最近一次复制内容
- 三栏资料库：左侧分类树、中间记录列表、右侧内容查看器
- 中栏记录区带纵向滚动条；标题旁的握柄可收起或展开左侧资料库，为记录区腾出空间
- 三栏使用独立的深浅底色、标题卡片和分隔线，亮色与暗色模式下都能清楚辨认边界
- 中栏提供常驻横向搜索块，可切换关键词、书名、文件名、主题筛选、AI 描述搜索并一键清除
- 每条记录前有可直接点击的复选框，可全选后批量移动、修改主题、导出或删除
- 主界面右栏支持选中文字后右键使用荧光笔、下划线、文字批注、清除格式与删除批注
- 文字批注显示为正文下方的折叠卡片，默认收起；展开时会定位并选中对应原文
- 夜间模式使用低亮度深金色荧光笔和高对比文字，并自动适配旧记录中的亮黄色标记
- 简洁单菜单栏：常用功能收进下拉菜单，三栏标题区各只保留一个“操作”入口
- 所有窗口使用圆角和统一的扁平化视觉；软件外壳支持日间、夜间模式
- 软件设置提供小、中、大三档界面字号，并采用低眩光亮色与夜间深色配色
- 大字号会同步扩展顶栏、标题栏和搜索操作区；空间不足时搜索控件自动换行，不再裁掉“全选”“AI 搜索”等文字
- 设置中可切换简体中文或 English；安装器也可在安装前选择语言
- 顶部“帮助 → 零基础使用手册（PDF）”可直接打开随程序安装的图文教程；“关于 Clypsera”也会提示该入口
- 阅读器为普通文档和 PDF 提供护眼绿、羊皮纸、黑色、白色四种阅读纸张并记住选择
- Word/DOCX 阅读会自动修复常见编码错读，并保留标题层级、字体、字号、颜色、粗体、换行、段落间距和表格结构；旧导入文件会自动重建新版阅读缓存
- PDF、Word 和 EPUB 底部统一提供 25%–300% 的无刻度连续缩放条，可按 1% 自由拖动
- “文件 → 导入文件夹”可递归导入整个资料目录，保留原有子文件夹层级，并自动收录其中支持的文档和电子书
- 导入文件夹时可选择“普通文件夹”或带 `🔄` 标记的“活动文件夹”；活动文件夹在启动时和运行期间持续同步源目录的新增、修改、重命名与删除，源目录暂时不可用时会保留资料库副本而不会误删
- 双击资料树、主记录或右栏正文即可打开归档原文；点击书内批注，Word/EPUB 按摘录原文定位，PDF 按批注页码跳转
- 书内右侧批注支持右键“请跳转到批注位置”；定位会依次尝试完整摘录、忽略空白差异、分行文本和特征片段，并高亮标出结果；失败时会明确提示原因
- PDF 跳转优先使用软件保存的摘录进行隐藏式精确定位，不要求用户输入；摘录不可用时会强制重新载入保存页码
- Word、EPUB 和 Markdown 的旧定位锚点失效时，会从保存摘录重建新锚点后再跳转
- PDF 批注有页码时直接跳页；旧批注页码为 0 时自动打开 PDF 内置搜索并查找摘录，不再静默无反应
- 主记录栏与书内批注栏均有可见“全选”复选入口；书内勾选批注可直接导出为 TXT、MD、PDF、Word、CSV 或 JSON
- “新建 → 手动粘贴或录入”在暂停采集时仍可保存文字，并可直接归入当前文件夹、文档或书籍
- 主要编辑、归档、删除、批注和手动录入操作支持 Ctrl+Z 撤销，最多保留最近 40 步
- PDF 阅读区会随阅读窗口同步放大或缩小，右侧批注栏保持稳定宽度
- 阅读器“⋯”更多工具、选中文字右键菜单和主界面右栏都提供 `✨ 请解释`
- 英文单词自动采用词典式释义；中文或较长句段进入可连续追问的 AI 解释对话
- AI 问询窗口采用独立的标题、对话和输入三区布局，滚动条不会再被输入框覆盖；底部按钮可完整显示
- “AI 整理排版”会先把原文拆成不可修改的编号单元，AI 只返回段落编号组合，最终正文始终由本机原文重新拼装；AI 无法改动字词、标点和顺序，编号方案异常时会自动纠正或使用本地安全排版
- AI 排版、AI 搜索/问答和手动 AI 自动归档在等待期间显示阶段进度条、当前步骤与已用时间，便于确认程序仍在正常工作
- PDF 阅读器底部提供 25%–300% 横向缩放滑条，并带减小、100% 复位和放大按钮
- 新建批注的来源统一显示为“Clypsera 阅读器”，旧版“简记/剪迹阅读器”记录会自动迁移
- 图书批注会同步成为主窗口中栏记录；选择对应图书即可查看全部批注
- 阅读器中选中文字后右键可直接高亮、下划线、添加批注或删除所选批注
- 自由创建嵌套文件夹和文档，拖动文件夹/文档即可调整树结构
- 可创建“书籍”节点，并分别按关键词、书名或文件名进行本地搜索
- 把 TXT、MD/Markdown、PDF、DOCX、DOC、EPUB、MOBI、AZW3/AW3 直接拖进左栏或中栏即可归档
- 双击导入文件，在内置阅读器中阅读；工具栏使用紧凑图标，`🎨` 可切换护眼绿、羊皮纸、黑色和白色阅读主题
- 选中文字后，可用 `🖍` 荧光笔、`U̲` 下划线、`📝` 批注，并从批注列表删除
- 导入文件会复制到资料库，批注实时保存；不会改动原始来源文件
- 记录可直接归入文件夹、文档或书籍；中栏支持 Ctrl/Shift 多选并批量移动
- 本地规则主题分类；可选 DeepSeek 根据现有文档树自动选择归档位置
- 右侧选中文字可直接高亮、添加下划线或清除格式
- 弹出式小编辑器支持修改正文、格式化和保存
- 左栏、中栏、右栏可以分别显示或隐藏
- 搜索、按主题筛选、复制回剪贴板、删除，并按单条、已选、当前分类或筛选结果导出
- 导出支持 TXT、Markdown、PDF、Word、CSV、JSON，可合并为一个文件，也可逐条放入同一导出文件夹
- 可选只读本地 API，方便和其他软件衔接
- AI 搜索浮窗支持自然语言描述和连续追问，搜索会话关闭即消失，不写入历史
- AI 问询浮窗可解释或总结选中内容；只有点击“保存问答”才会写入历史
- `Ctrl+Shift+V` 安全粘贴：本机先拦截敏感内容，再由 AI 审核或修复乱码
- 可选随 Windows 启动

## 使用

1. 如果旧版正在运行，先右键它的托盘图标并选择“退出”。
2. 运行 `Clypsera-v26-Setup.exe`，先选择安装语言；如需更换安装位置，点击“浏览”并在文件夹窗口中选择目录，再点击“安装”。安装器会自动检测 Microsoft WebView2；缺失时会显示进度并从微软官方通道补装。
3. 从桌面或开始菜单打开“Clypsera”。首次启动后它会缩到托盘，悬浮窗会出现。
4. 复制任意文本。双击托盘图标打开完整记录。
5. 在顶部“新建”下拉菜单或左栏“操作”中创建文件夹、文档或书籍。
6. 将文档、电子书或整个文件夹拖入左栏/中栏，也可使用“文件 → 导入文档 / 导入文件夹”；导入后双击左栏文件开始阅读。
7. 从中栏把一条或多条记录拖到左栏的文件夹、文档或书籍；也可以使用“整理 → 移动到文件夹或文档”。
8. 使用“文件 → 导出”选择范围、格式与“合并 / 逐条”方式；左栏和中栏的操作菜单也有对应快捷入口。
9. 在“文件 → 设置”里可启用 DeepSeek。API Key 使用 Windows 加密后保存在本机。
10. 关闭主窗口只会隐藏；需要退出时右键托盘图标选择“退出”。

## 文档与电子书

- **TXT**：离线阅读，自动识别 UTF-8、UTF-8 BOM、UTF-16 和常见中文 GBK 编码，并保留原有换行与段落。
- **MD/Markdown**：离线转换为安全阅读页，支持标题、列表、引用、代码块、加粗、斜体和链接，并可在阅读器中高亮、下划线和添加批注。
- **PDF**：由 Microsoft Edge WebView2 的内置 PDF 阅读器显示，支持护眼绿、羊皮纸、黑色、白色四种页面主题。可继续使用 PDF 工具栏提供的缩放、选择和保存能力；Clypsera 右侧批注栏另行保存页码、摘录和批注。
- **DOCX**：读取 Word Open XML 正文并生成离线阅读页，支持 Clypsera 荧光笔、下划线和批注。
- **DOC**：使用兼容文本提取回退。复杂排版可能无法还原，建议另存为 DOCX 后导入。
- **EPUB**：读取书籍清单和章节顺序，合并成离线阅读页；脚本和不安全嵌入内容会被移除。
- **MOBI、AZW3/AW3**：内置支持无 DRM 的未压缩或 PalmDOC 压缩正文。复杂 HuffDic/KF8 文件会尝试调用已安装的 Calibre；带 DRM 的电子书无法读取。

导入文件归档于 `%LOCALAPPDATA%\ClipboardTrail\library-files`，批注保存在 `%LOCALAPPDATA%\ClipboardTrail\annotations.json`。删除程序时个人资料默认保留。

内置阅读器依赖 Microsoft Edge WebView2 Runtime。Windows 10/11 通常已经安装；v26 安装包会先检查系统注册信息，已安装时直接跳过，缺失时从微软官方 Evergreen Bootstrapper 通道下载、校验 Microsoft 签名并静默补装。补装需要可连接微软下载服务的网络。

## 搜索与 AI 对话

- “搜索”下拉菜单提供关键词、书名、文件名和主题筛选，完全在本机运行；筛选状态会显示在中栏标题。
- “AI 搜索”会打开置顶对话浮窗，可以用自然语言描述要找的内容并连续缩小范围。为控制上下文，最多使用最近 120 条非敏感记录作为候选；关闭窗口后对话和结果不会保存。
- 选中一条记录后点击“AI 问询”，可询问含义或生成总结。问询默认不保存，只有点击浮窗中的“保存问答”才会新增一条 `AI问答` 记录。
- 明显包含密码、验证码、密钥或来自密码管理器的记录不会发送给 AI。

## 安全粘贴

把光标放在目标软件的输入位置，按 `Ctrl+Shift+V`。Clypsera 会先在本机检查密码、验证码、银行卡号、私钥、API 密钥和疑似独立凭据。明显敏感的内容直接阻止，不会发送给 DeepSeek。其余内容在启用 DeepSeek 后会接受 AI 审核；若是可修复的乱码，会整理后再粘贴。

普通的 `Ctrl+V` 仍保持 Windows 原有行为，不经过审核，避免软件通过全局键盘钩子强制接管系统输入。如果全局快捷键被别的软件占用，可从 Clypsera 界面的“安全粘贴”按钮查看使用说明。

## DeepSeek

默认接口：`https://api.deepseek.com/chat/completions`，默认模型：`deepseek-chat`。启用后，非敏感的新复制文本最多会发送前 4000 字，并附带最多 120 个已有文档路径。AI 会返回主题分类，并从你的文档树中选择合适的归档文档；没有合适文档时保持未归档。未启用时，任何剪贴板内容都不会发送到网络。

## 本地 API

默认关闭。启用后只监听本机回环地址：

- `GET http://127.0.0.1:17654/api/status`
- `GET http://127.0.0.1:17654/api/latest`
- `GET http://127.0.0.1:17654/api/items?limit=100`
- `GET http://127.0.0.1:17654/api/tree`

该接口只读、仅限本机，但没有额外口令；共享电脑上请按需开启。

## 数据位置和限制

记录保存在 `%LOCALAPPDATA%\ClipboardTrail\history.jsonl`，资料库树保存在同目录的 `library.json`。升级版兼容旧版历史。程序不能精确获得“网页 URL”或原始文档路径；来源采用复制瞬间的前台程序名和窗口标题。密码管理器等敏感软件若把内容写入系统剪贴板，也可能被本地记录，处理敏感内容前可从托盘暂停采集。

## 从源码构建

在 Windows PowerShell 中运行 `Build.ps1`。它使用系统自带的 .NET Framework 编译器，不下载第三方依赖。
